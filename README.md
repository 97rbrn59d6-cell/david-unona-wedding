# David & Unona — Wedding Invitation

Бесплатный статический сайт-приглашение для GitHub Pages.

## Что уже готово
- Адаптивный дизайн для телефона и компьютера
- Бордовая, золотая и айвори палитра
- Анимации появления и плавная прокрутка
- Обратный отсчёт до 6 июня 2027, 18:00 (Актау, UTC+05:00)
- Секции для фотографий
- Поиск Qaraqat Hall в Google Maps (это поиск по названию, не подтверждённый точный адрес)
- Форма RSVP с подготовленной интеграцией Formspree
- Кнопка управления музыкой

## 1. Добавить фотографии
Положите три своих изображения в папку `assets` и назовите их:
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

Можно использовать `.jpg` или `.webp`, но если используете другое имя/расширение, измените `src` в `index.html`.
Используйте только фотографии, которыми вы имеете право делиться.

## 2. Добавить фортепианную музыку
Добавьте в папку `assets` файл `piano.mp3`.
Используйте свою запись, музыку с подходящей лицензией или трек, разрешающий публикацию на сайте. Не скачивайте произвольную коммерческую песню.
На телефонах музыка не начнёт играть автоматически — посетитель должен нажать кнопку «Включить музыку».

## 3. Подключить RSVP (Formspree)
GitHub Pages не обрабатывает формы сам по себе. Formspree предоставляет форму с бесплатным тарифом/лимитами, которые могут меняться; проверьте актуальные условия перед использованием.

1. Откройте https://formspree.io/ и создайте аккаунт.
2. Создайте новую форму и укажите email, на который хотите получать ответы.
3. Подтвердите email, если сервис попросит.
4. Скопируйте endpoint формы вида `https://formspree.io/f/abcdefgh`.
5. В `index.html` найдите:
   `action="https://formspree.io/f/YOUR_FORM_ID"`
6. Замените `YOUR_FORM_ID` на настоящий ID, например endpoint станет `https://formspree.io/f/abcdefgh`.
7. Сохраните файл и загрузите обновление в GitHub.
8. Отправьте тестовый ответ и проверьте, что он пришёл на email.

Если не хотите подключать внешний сервис, можно заменить RSVP-форму на кнопку WhatsApp, но это не будет формой с автоматическим сбором ответов.

## 4. Создать новый репозиторий GitHub
1. Зайдите на https://github.com/ и войдите в аккаунт.
2. Нажмите `+` вверху справа → `New repository`.
3. Название, например: `david-unona-wedding`.
4. Выберите `Public` (для бесплатного GitHub Pages).
5. Нажмите `Create repository`.
6. В репозитории нажмите `Add file` → `Upload files`.
7. Загрузите `index.html`, `style.css`, `script.js`, `README.md` и папку `assets` с её файлами. Важно: `index.html` должен лежать в корне репозитория, не внутри вложенной папки.
8. Нажмите `Commit changes`.

## 5. Включить GitHub Pages
1. В репозитории откройте `Settings`.
2. Слева выберите `Pages`.
3. В разделе Build and deployment выберите `Deploy from a branch`.
4. В Branch выберите `main`, папку `/ (root)`.
5. Нажмите `Save`.
6. Подождите несколько минут и обновите страницу Settings → Pages. Там появится опубликованная ссылка.

Адрес обычно будет вида:
`https://ВАШ-ЛОГИН.github.io/david-unona-wedding/`

Название URL зависит от вашего GitHub-логина и названия репозитория. Свободный короткий адрес нельзя гарантировать заранее.

## 6. Обновить сайт
Когда меняете файл, откройте его в GitHub, нажмите значок карандаша или загрузите обновлённый файл, затем `Commit changes`. Публикация обновится через некоторое время.
